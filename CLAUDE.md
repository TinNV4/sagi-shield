## Project

**Sagi Shield（サギシールド）** — a real-time AI guard against phone scams (オレオレ詐欺 / ニセ警察詐欺 in Japan, fake-công-an scams in Vietnam). Entry for the Google Cloud AI Builder Cup 2026, BFSI track.

`docs/PLAN.md` is the **single source of truth** for scope, decisions, API contracts and phase checklists. Read the relevant section before changing anything; tick its checkboxes when a phase item is done. `docs/AGENT_RULES.md` holds the working rules for coding agents; the constraints below are the ones that bite most often.

## Commands

All Python commands run from `backend/`.

```bash
pip install -r requirements.txt
cp ../.env.example ../.env          # then fill in project / key

# rules regression tests (no network, no LLM) — the fast inner loop
python -m pytest tests -q
python -m pytest tests -q -k smoke_cases          # single test / subset
python -m pytest tests/test_risk_engine.py::test_news_about_scams_is_not_high_by_rules_alone

# CLI smoke tests (each core module is its own entry point)
python core/risk_engine.py --lang ja --no-llm --text "警察です。口座が犯罪に使われています。LINEで逮捕状を送ります"
python core/input_layer.py --lang vi --text "Công an đây, gọi lại +85598765432, vào https://vneid-xacminh.top"

# dataset + eval
python core/gen_dataset.py seed --lang ja --out eval/ja_seed.jsonl     # offline templates
python core/gen_dataset.py gen  --lang vi --n 100 --out eval/vi.jsonl  # needs Gemini credentials
python core/gen_dataset.py eval --data eval/ja_seed.jsonl --lang ja --no-llm
```

`--no-llm` everywhere means "rules only, no network". Use it by default; the repo-root `.env` (loaded automatically) holds the key for real LLM runs — with an API key, `GOOGLE_GENAI_USE_ENTERPRISE` must be `false`.

## Architecture

Three layers, deliberately kept as standalone, CLI-runnable modules so each can be tested alone. The FastAPI app (`backend/app/`, not written yet) is meant to be a thin wrapper over them — **extend `backend/core/*`, never rewrite it**.

**`core/input_layer.py` — normalization.** Every input shape (text / image / audio file / phone / URL) collapses into one `Evidence` object via `build_evidence()`. Text is NFKC-normalized (full-width ＬＩＮＥ → LINE), zero-width chars and dash variants stripped, Vietnamese gets a no-diacritics variant. Phone numbers and account numbers are extracted and **masked out of `ev.text` before it reaches logs or the LLM**; only a hash is kept. URLs are flagged (shortener / punycode / ip_host / suspicious_tld / brand lookalike) **without ever fetching them**. Images are resized and re-encoded to drop EXIF.

**`core/risk_engine.py` — scoring.** A five-stage scam kill chain (`Stage`: AUTHORITY → FEAR → ISOLATION → CHANNEL_SWITCH → MONEY) with per-market `LANG_PACKS` (regex patterns, advice strings, hotlines) — adding a market means adding a pack, not touching the engine.

The rule layer scores **co-occurrence of links, not the deepest single keyword** (a fix for measured false positives; PLAN section 6.2). 1 link ≤ 30 = LOW, 2 links 45–55 = MEDIUM, 3+ ≥ 70 = HIGH. `HARD_COMBOS` are pairs with no legitimate version (authority + channel switch → floor 90) and must stay non-vetoable by the LLM. `is_reporting()` detects text *about* scams (news, police warnings) and caps the **rules** at `REPORTING_CAP` = 55 — the LLM can still raise it, so a scammer can't silence the alarm by saying 「手口」.

`LiveTracker` holds state for **one call**: hits accumulate across windows (the chain unfolds over minutes, a window holds ~30 s), stages never go backwards, the LLM score is EMA-smoothed, and once HIGH it latches until `reset()` (called on the silence timeout, so an 8 pm TV drama doesn't poison a 9 pm call).

**`core/gen_dataset.py` — data + eval.** No public JP/VN scam-call dataset exists, so `gen` synthesizes transcripts with Gemini (60% scam, hard negatives that mention banks/police/money legitimately), `seed` writes offline templates for smoke tests, `eval` reports recall / precision / FPR against `risk_engine.analyze()`. Note `tests/test_risk_engine.py` imports `SEED` from here — the seed texts are also regression fixtures.

**`frontend/`** is a static React + Vite PWA (no server, no secrets): `src/api/client.ts` holds `RealApi` (used when `VITE_API_BASE` is set) and `MockApi` (DEMO badge); `src/lib/liveGuard.ts` runs on-device speech recognition and must only claim "on-device" when `SpeechRecognition.available()` says so. Commands, from `frontend/`: `npm install`, `npm run dev` (port 3000), `npm run lint` (tsc), `npm run build`. On this Windows machine run npm through PowerShell — in Git Bash the command hook mangles its arguments.

**`frontend/lib/audioCapture.js`** — AudioWorklet mic → 16 kHz mono PCM16, 100 ms chunks → `WS /ws/live`. Still missing the VAD gate, `pause()` and WS auto-reconnect (PLAN section 7). The rest of `frontend/` is generated by AI Studio Build from `docs/AI_STUDIO_UI_PROMPT.md` and exported here once — **do not round-trip** through AI Studio.

**`backend/app/` — HTTP API (PLAN section 9).** `main.py` is the thin FastAPI wrapper: `/check` (JSON or multipart), `/precheck`, `/report`, `/stats`, `/health`. Rules that sit outside the text engine (official document in an image, Web Risk hit, "police asked me to pay") lift the result through `raise_to()`. `services.py` holds every Google call (vision, transcription, Web Risk) and each one degrades to `None` / `[]` — an enrichment failing must never fail a check. `storage.py` is `MemoryStore` by default, `FirestoreStore` with `STORE=firestore`. Run it with `uvicorn app.main:app --port 8080`; env switches: `USE_LLM=0`, `USE_WEBRISK=1`, `STORE`, `CORS_ORIGINS`, `HASH_KEY`. Tests stub the services and run with `USE_LLM=0`.

**Privacy tiers (PLAN 6.9) drive the Live Guard design: audio never leaves the device.** STT runs in the browser (Web Speech API, `processLocally`); `app/live.py` (`WS /ws/live?input=text`) receives finalized transcript lines only, masks numbers on arrival, runs rules on every line, and sends the masked rolling window to Gemini on a clock (`gate=periodic`, default) or only once rules reach MEDIUM (`gate=rules`), always off the receive loop. Do not add a code path that uploads audio by default — server-side STT is an explicit opt-in fallback and is not implemented. `frontend/spike/live_text.html` (served at `/spike/` in dev) is the on-device STT test page.

**`app/agent.py` — F6 recovery agent (google-adk 2.x).** The checklist (steps, phone numbers) is deterministic server content; the model only talks and changes state through three tools. Nothing is kept in the process: each turn runs in a throw-away ADK session seeded from `STORE.get_recovery()` (state + masked turns), because Cloud Run instances are interchangeable. The instruction is a callable, so ADK's `{placeholder}` templating never touches it. Any model failure falls back to `scripted_reply()`.

Fusion (`fuse()`): a hard combo is final; otherwise `score = c·LLM + (1−c)·rules` with c = LLM confidence, so the LLM can raise *or lower* the rules. `LiveTracker` fuses the same way and latches after 2 consecutive HIGH updates. Its call-level accumulation is *soft* (LLM-vetoable); hard combos count only when their links fall within the last `HARD_WINDOW` updates.

## Constraints

- **Contest rules:** fresh code only — never paste from older projects. **All code, comments, docs and commit messages in English**; UI strings may be ja/vi/en.
- **Google stack only** for infra: Gemini on Agent Platform (the 2026 rename of Vertex AI), Gemini transcribe-live / Chirp 3 STT, Cloud Run, Firestore, Web Risk, FCM, Firebase Hosting.
- **Model IDs, project IDs and keys live only in `.env`.** Current default is `gemini-3.8-flash`, served from `GOOGLE_CLOUD_LOCATION=global`; Cloud Run / Firestore stay in `asia-northeast1`.
- **SDK currency — training data is stale here.** `google-genai` 2.x uses `GOOGLE_GENAI_USE_ENTERPRISE` (not `..._USE_VERTEXAI`), `session.send_realtime_input(...)` on the Live API, and `thinking_level` (not `thinking_budget`) on Gemini 3.x. `google-adk` 2.x broke the 1.x agent API, so 1.x examples do not run. `gemini-3.5-transcribe-live` sessions hard-stop at 10 minutes → always implement rotation. Check current docs before writing Gemini/ADK code.
- **Privacy:** never store raw audio; mask PII before logging; transcripts and OCR text are *untrusted data*, never instructions — keep output schema-constrained.
- **Never output "100% safe"**; keep user-facing text short and calm. LOW still advises verifying via an official number.
- Police-published audio is **private evaluation only** — never committed (`backend/eval/real_heldout/` is git-ignored) and never in the demo video.
