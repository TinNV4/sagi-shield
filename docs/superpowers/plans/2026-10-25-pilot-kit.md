# Pilot Kit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Everything a family needs before they are asked to install Sagi Shield, and everything the owner needs to run the pilot honestly: a privacy notice the app links to, data that expires on its own, a pilot protocol with the weekly check-in, and a one-command weekly summary.

**Architecture:** Retention is enforced by the stores, not by prose: alerts carry an `expires_at` Firestore timestamp with a TTL policy (90 days), feedback the same (365 days), the verdict dataset gets a default partition expiration. The privacy notice is structured content per language (`src/content/privacy.ts`) rendered by a `PrivacyScreen` at `/#privacy`, linked from Settings, onboarding and the setup card. The pilot protocol lives in `docs/PILOT.md` (owner side) with a family-facing one-pager in ja and vi; `tools/pilot_report.py` prints the weekly numbers from BigQuery and Firestore with the gcloud token path the other tools use.

**Tech Stack:** FastAPI, Firestore TTL policies, BigQuery, React 19 + Vite, vitest, PowerShell setup scripts, Terraform.

**Spec:** `docs/ROADMAP.md` section 4, step 4 ("pilot kit and consent") and section 3 goal 4; the privacy wording in `docs/PLAN.md` section 13; the lawyer-review open question stays open (docs say so).

## Global Constraints

- Branch `pilot` only; `main` and `.github/workflows/deploy.yml` untouched until 2026-11-07.
- The privacy notice must be true to the code on this branch: audio never leaves the device (opt-in cloud recogniser excepted and labelled), only masked text reaches Gemini on `global` endpoints, alerts hold a summary sentence, no transcripts stored, reports hashed, deletion through the household owner, retention figures exactly as implemented.
- Never promise "100% safe"; UI text short and calm; ja / vi / en with key parity for i18n keys; the long notice content has its own parity test.
- Retention: alerts 90 days, feedback 365 days, verdict dataset partitions 400 days (same as `sagi.events`), recovery sessions already 24 h.
- Backend tests offline; frontend `npx vitest run --pool=threads` (default pool if it fails), `npm run lint`, `npm run build`; CRLF preserved; no AI attribution trailer; Google stack only.

### Task 1: Retention in the stores and the infrastructure

**Files:**
- Create: `backend/app/retention.py`, `frontend/src/content/retention.json`
- Modify: `backend/app/storage.py`, `infra/setup_pilot.ps1`, `infra/setup.ps1`, `infra/setup_verdict_sink.ps1`, `infra/terraform/main.tf`
- Test: `backend/tests/test_retention.py`, `backend/tests/test_household_store.py`

**Interfaces:**
- `retention.ALERT_DAYS = 90`, `FEEDBACK_DAYS = 365`, `VERDICT_PARTITION_DAYS = 400`; `retention.expires_at(days: int, now: float | None = None) -> datetime` (UTC, tz-aware).
- `_alert(...)` adds `expires_at`; `MemoryStore` stores the ISO string (`isoformat(timespec="seconds")`), `FirestoreStore.add_household_alert` / `add_alert` and `save_feedback` write the `datetime` (TTL policies need a timestamp field; `recovery_sessions` already does this). `list_household_alerts` / `list_alerts` strip nothing (the field is harmless in the API; the PWA ignores unknown fields) but must tolerate documents without it.
- `frontend/src/content/retention.json`: `{"alert_days": 90, "feedback_days": 365, "verdict_days": 400}`; `test_retention.py` asserts the JSON equals the constants.
- Scripts: `gcloud firestore fields ttls update expires_at --collection-group alerts --enable-ttl --async` and the same for `feedback` (pilot: `--database $Database` in `setup_pilot.ps1`; default database in `setup.ps1`); `setup_verdict_sink.ps1`: `bq update --default_partition_expiration=34560000 <project>:<dataset>` after creation (400 days in seconds); Terraform: two `google_firestore_field` TTL resources per database (`alerts`, `feedback`) and `default_partition_expiration_ms = 34560000000` on the verdict datasets.

def test_retention_constants_match_the_frontend_json():
